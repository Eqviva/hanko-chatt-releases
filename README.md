# Hanko Chatt

Installationsfiler och uppdateringar för Hanko Chatt, AI-chatten för bokföring med Hanko. Koden finns inte här.

Installera med `Hanko-Chatt-<version>-x64.exe` från den [senaste releasen](https://github.com/Eqviva/hanko-chatt-releases/releases/latest).
Appen letar själv efter nya versioner och uppdaterar sig från den här sidan.
